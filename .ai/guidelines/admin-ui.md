# Admin UI

- Admin UI design base: the Paces Tailwind theme (https://themes.coderthemes.com/paces/tailwind/index.html). The admin layout (sidebar, top bar, page structure) and its elements are built on it step by step, rebuilt with Flux components + Tailwind utilities (not the theme's own CSS/JS), in both light and dark mode.
  - Paces design tokens live in `resources/css/app.css` (`@theme` + `.dark` overrides) — use them instead of raw colors: `bg-body-bg`, `text-body`, `bg-card`, `border-line`, `text-muted`, `bg-primary`/`text-primary` (+ `secondary`, `success`, `info`, `warning`, `danger`), `bg-topbar-bg`, `text-topbar-item`, `bg-sidenav-bg`, `text-sidenav-item`, `rounded-card`, `shadow-card`, spacing `gap-base`/`mb-base` (20px), `min-h-topbar` (65px), `w-sidenav` (245px). Flux's `zinc` scale and `accent` are mapped onto the Paces grays/primary. Font: Nunito (bunny, `vite.config.js`).
  - Admin building blocks (`resources/views/admin/components`): `<x-admin-page-title :title>` at the top of every page (no breadcrumbs in the admin; the slot holds page actions), `<x-admin-card :title>` (slots: `actions`, `footer`; `flush` for no body padding), `<x-admin-nav-title>` + `<x-admin-nav-item :href icon :current>` for sidenav entries in `admin/layouts/app/sidebar.blade.php`, `<x-admin-nav-group :label icon :current>` with `<x-admin-nav-sub-item>` children for a dropdown, `<x-admin-stat-card>` for stat tiles, `<x-admin-chart type="area|bar|donut" :data>` for charts (ApexCharts via `resources/js/charts.js`, include it with `@vite('resources/js/charts.js')`; the categorical palette there is validated for both modes — don't add colors without re-validating), `admin.partials.pagination` as the Livewire pagination view. Scrollable dark areas (the sidenav) use the `scrollbar-sidenav` utility from `resources/css/app.css`: the Paces SimpleBar look (thin rounded primary thumb, visible on hover) without the library. List pages follow `admin/users/index.blade.php` (Paces products table: search + filters + per page in the card header, sortable columns, bulk delete, icon action buttons).
- Every UI element must work in both light and dark mode.
- Every button and clickable element must have `cursor-pointer` (buttons, links styled as buttons, dropdown/menu items, toggles, checkboxes, radios). There is a global base rule in `resources/css/app.css` as well, but add `cursor-pointer` explicitly to custom clickable elements.
